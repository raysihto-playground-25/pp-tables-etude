# 日本語表記規則

このドキュメントは、本プロジェクトのドキュメント全般に適用する日本語表記の規則を定める。

## 外来語の表記（長音符の扱い）

### 原則

外来語を片仮名で表記する際は、**語末または語中の長音を省略しない**。

- **正**: セキュリティー、ブラウザー、コンテナー、プロバイダー
- **誤**: セキュリティ、ブラウザ、コンテナ、プロバイダ

### 根拠

#### 内閣告示第2号（外来語の表記）

[内閣告示第2号「外来語の表記」（平成3年）](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikakukokuji/gaikokugo/index.html)に示す留意事項において、語末が長音になる場合は長音符「ー」を付けることを基本とする旨が示されている。

#### Microsoft スタイルガイド（日本語）

[Microsoft ローカリゼーション スタイル ガイド（日本語）](https://learn.microsoft.com/ja-jp/globalization/reference/microsoft-style-guides) においても、外来語末尾の長音符を省略しないことを推奨している。

### 適用例

| 表記すべき語 | 正しい表記 | 誤った表記 |
|---|---|---|
| security | セキュリティー | セキュリティ |
| browser | ブラウザー | ブラウザ |
| container | コンテナー | コンテナ |
| provider | プロバイダー | プロバイダ |
| folder | フォルダー | フォルダ |
| layer | レイヤー | レイヤ |

### 例外

固有名詞や商標名・サービス名など、公式の表記が長音符なしと定められているものはその限りでない（例：製品名として「Mozilla Firefox」等）。

また、複合語の前半要素として使われる場合は、文脈・読みやすさを考慮して判断してよい。
